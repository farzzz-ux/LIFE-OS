## Reporting a Vulnerability

The LIFE OS team takes security and user privacy seriously. If you discover a potential vulnerability (e.g. multi-tenant data leakage, stored XSS, CSRF, or authentication bypass):

1. **Do not** open a public issue on GitHub.
2. Please disclose responsibly by contacting: **farzinprsnl0@gmail.com**
3. Include:
   - Detailed steps to reproduce
   - Potential impact
   - Proof-of-concept payload or script (if available)

We will respond promptly to investigate and deploy fixes to production.
